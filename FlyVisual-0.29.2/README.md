# FlyVisual

Визуальный клиентский мод для Minecraft **1.20.1** (Fabric). Красная тема по умолчанию, цвет меняется в меню.

## Что нового в 0.8: плащи

- Новый модуль **Плащи**. Выбор плаща ползунком «Плащ» в настройках модуля.
- Встроенные: Фирменный FlyVisual, Красный глаз, Чёрный, Закат, Обсидиан, Ночные горы, Синие облака.
- Плащ виден только тебе и только от третьего лица (F5). Если надеты элитры, плащ ложится и на них.
- В настройках скина (Настройки, Настройки скина) должна быть включена деталь «Плащ».
- **Свои плащи:** положи PNG-файл плаща (раскладка Minecraft, соотношение сторон 2:1, например 64×32 или 1024×512) в папку `flyvisual/capes` внутри папки игры (`.minecraft`) и перезапусти игру. Имя файла станет названием плаща в списке.

## Что нового в 0.7

- **Время суток:** своё время суток (ползунок «Время (часы)», 12 = полдень, 0 = полночь). «Скорость времени» больше нуля заставляет время идти. Видно только тебе.
- **Обводка блока:** свой цвет обводки блока, на который смотришь (цвет, прозрачность, радуга, пульсация).
- **Анимация тотема:** можно уменьшить (ползунок «Размер») или скрыть совсем («Скрыть анимацию»).
- **Прицел:** свой прицел. Формы: плюс, крест, точка, круг. Настройки: размер, толщина, зазор, цвет (в том числе радуга и цвет темы), чёрная обводка, покраснение на цели. Пока включён, ванильный прицел и индикатор атаки скрыты.

## Что нового в 0.6: главное меню FlyVisual

- Вместо ванильного главного меню: твой фон (`assets/flyvisual/textures/gui/title_bg.png`), логотип FlyVisual со свечением, закруглённые серо-чёрные кнопки с красной обводкой (цвет берётся из темы).
- Кнопки: Одиночная игра, Сетевая игра, Настройки, Моды, Выход. Кнопка «Моды» открывает список установленных модов.
- Живой фон: медленное приближение и смещение за мышкой, колыхание листвы сверху и травы внизу, пульсирующие лучи света, дрейфующий туман, падающие красные листья и искры.
- Всё плавно появляется при запуске, кнопки плавно подсвечиваются при наведении.
- Настройки в `config/flyvisual.json`:
  - `"customTitleScreen": false` вернёт обычное меню Minecraft;
  - `"titleWave": false` выключит колыхание фона;
  - `"titleParticles": false` выключит лучи, туман и листья.
- Чтобы поменять картинку, замени файл `title_bg.png` (лучше 1920×1080) и пересобери мод.

## Что нового в 0.5

- **Новое меню в ширину** (Right Shift): слева плитки модулей, справа настройки выбранного модуля. ЛКМ по плитке включает/выключает, ПКМ только выбирает. Колесо мыши прокручивает.
- **Плавные анимации:** меню плавно открывается и закрывается, переключатели плавно двигаются.
- **Весь интерфейс на русском:** меню, настройки, уведомления, надписи на HUD, названия клавиш.
- **Low Fire** без настроек, только вкл/выкл.
- **Эффекты зелий** стали компактнее: иконка эффекта, уровень и время. Название можно включить в настройках («Показывать названия»).
- **Частицы урона:** частицы при ударе (крит, искры, сердечки, огонь, звёзды, тотем, дым, зелёные звёзды, салют, синий огонь). Настройки: тип, количество, разлёт, только криты. Видны только тебе.
- Файл `-sources.jar` больше не создаётся, в `mods` кладётся единственный jar.

## Что нового в 0.4

- **TargetHUD:** здоровье, броня и расстояние до того, на кого смотришь (настройки: время показа, только игроки, броня). В HUD-редакторе показывается образец.
- **Hitboxes:** свои хитбоксы с выбором цвета (Color hue, Brightness, Opacity, Range, Players only). Рисуются за блоками, насквозь не видны.
- **Hitcolor:** свой цвет красной вспышки, когда по существу бьют (Color hue, Strength).
- **Fog:** убрать туман совсем (Remove fog) или сделать ближе/дальше (Distance). Под водой, в лаве, в Незере и при слепоте не работает.

Пока не сделано: прозрачность воды и лавы, цвет блеска зачарований (Glint Color). Это лезет в глубокие части рендера, отдельным шагом.

## Что нового в 0.3: настройки у каждой функции

ПКМ по модулю в меню открывает настройки. Там бывают ползунки и переключатели Вкл/Выкл.

- **Все HUD-модули:** Opacity (прозрачность фона), Scale (размер), Accent bar (цветная полоска)
- **Zoom:** Zoom level, Max zoom, Scroll speed, Smooth zoom, Smoothness
- **Fullbright:** Brightness
- **FreeLook:** Sensitivity, Third person
- **Lower Fire:** Offset
- **Hand Offset:** X, Y, Z, Scale
- **Coordinates:** Decimals (знаков после запятой)
- **Armor HUD:** Show durability %, Warn below %
- **Potion Status:** Show timer
- **Watermark:** Show nickname
- **NoHurtCam:** только вкл/выкл, как ты просил

## Что есть в версии 0.2

**Меню (Right Shift)**
- ЛКМ по модулю: включить/выключить
- ПКМ по модулю (или стрелка `>`): настройки с ползунками
- Колесо мыши: прокрутка списка
- Внизу: цвет темы и кнопка **HUD Editor** (перетаскивай модули мышкой, ESC для возврата)

**HUD:** Watermark, FPS, Ping, Coordinates, Keybinds (WASD/мышь/пробел), Armor HUD, Potion Status

**Камера и рука**
- **Fullbright**
- **NoHurtCam**: без тряски камеры при уроне
- **Lower Fire**: огонь на экране ниже (ползунок Offset)
- **Zoom**: держи `C`, колёсико меняет приближение, плавный вход и выход
- **FreeLook**: держи `Left Alt`, обзор на 360°, тело не поворачивается
- **Hand Offset**: сдвиг по X/Y/Z и размер предмета в руке

Клавиши можно поменять в настройках управления игры (категория FlyVisual).
Конфиг: `config/flyvisual.json`.

## Сборка через GitHub (без установки Java)

После каждого `git push` GitHub сам собирает мод: вкладка **Actions** → последний запуск → внизу **Artifacts** → `FlyVisual` (внутри jar).

## Сборка на своём компьютере

Нужно: **JDK 17** и **IntelliJ IDEA**. Открой папку проекта, дождись Gradle, затем `./gradlew runClient` (тест) или `./gradlew build` (jar в `build/libs`).

Чтобы играть, положи jar и **Fabric API 0.92.2 для 1.20.1** в папку `mods`.

## Как добавить новую функцию

1. Создай класс в `com.flyvisual.module.impl`, наследуй `Module` (или `HudModule`, если рисует на экране).
2. Настройки-ползунки: `addSetting("Имя", по умолчанию, мин, макс, шаг)`.
3. Добавь одну строку в `ModuleManager.init()`.

## Если что-то не работает

Миксины (Zoom, FreeLook, Lower Fire, Hand Offset, NoHurtCam) целятся в внутренние методы игры, и я не мог проверить их в запущенной игре. Если какая-то функция не работает, найди в `logs/latest.log` строки со словом `flyvisual` или `Mixin` и пришли их. Если игра вылетела при запуске, пришли файл из `crash-reports`.
